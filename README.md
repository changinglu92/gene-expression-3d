# 基因的表达 · 3D 互动课件

人教版 2019 必修 2 第 4 章第 1 节「基因指导蛋白质的合成」课堂用 3D 互动网页，含转录、翻译、多聚核糖体，以及溶酶体与 TMEM175 蛋白（帕金森案例，教学示意）。

## 在线打开

https://changinglu92.github.io/gene-expression-3d/

用手机或平板扫二维码，或在 Chrome / Edge 中直接打开即可，无需认领、无需登录。

扫码后会先进入【课前自诊】（学案 8 句判断题，先凭直觉、作答时不公布口径）。圈完后点「进入课件」，会先看到每题的正确判断和对应考点，再进入 3D 课件。老师也可「跳过，直接进入课件」。每次扫码或打开主页都会先弹出课前自诊；已经做过的同学会先看到对照结果，点「进入课件」后再进 3D。顶栏「自测」可重做。

进入课件后，左右讲义、中控台默认关闭。在平板上，顶栏标题、课堂分步和底部「上一步 / 下一步」也会收成小页签（「标题」「课堂分步」「上下步」），以免挡住核糖体和 mRNA。点页签即可重新打开，各窗口上都有「关闭 / 隐藏」。「先想一想」可以拖走或点「收起」，避免挡住 E、P、A 位点。

左上角标题已简化为「基因的表达」。

## 离线使用

下载本仓库中的 `index.html`，双击用 Chrome / Edge 打开即可离线使用。
