# 基因的表达 · 3D 互动课件

人教版 2019 必修 2 第 4 章第 1 节「基因指导蛋白质的合成」课堂用 3D 互动网页，含转录、翻译、多聚核糖体，以及溶酶体与 TMEM175 蛋白（帕金森案例，教学示意）。

## 在线打开

https://changinglu92.github.io/gene-expression-3d/

用手机或平板扫二维码，或在 Chrome / Edge 中直接打开即可，无需认领、无需登录。

扫码后会先进入【课前自诊】（学案 8 句，每题先判对/错/不确定，再选理由；先凭直觉、作答时不公布口径）。判断和理由都选完后点「对照结果」，会看到每题的正确判断、正确理由和对应考点，再进入 3D 课件。老师也可「跳过，直接进入课件」。每次扫码或打开主页都会先弹出课前自诊；已经做过的同学会先看到对照结果，点「进入课件」后再进 3D。顶栏「自测」可重做。

进入课件后，顶栏有「建构模型」，面板会在 3D 画面最下方展开：第一次是「构建基因到蛋白质的信息传递流程图」（转录、翻译放在相应箭头上方）；第二次在已经接好的「基因→mRNA→TMEM175蛋白」基础上，「构建 TMEM175 蛋白致病机理模型」。都可拖动卡片和箭头来搭；若有错会先给提醒和支架，不会第一次就摊开完整答案。左右讲义、中控台默认关闭。在平板上，顶栏标题、课堂分步和底部「上一步 / 下一步」也会收成小页签（「标题」「课堂分步」「上下步」），以免挡住核糖体和 mRNA。点页签即可重新打开，各窗口上都有「关闭 / 隐藏」。「先想一想」可以拖走或点「收起」，避免挡住 E、P、A 位点。

左上角标题为「基因的表达·导航线」，右下角有「深圳实验学校高中园 生物组」。课堂步骤：细胞总览、转录场所与条件、碱基互补配对、mRNA 出核、翻译、多聚核糖体与效率、中心法则、分泌蛋白与溶酶体膜蛋白、溶酶体与 TMEM175 蛋白。

学校平板请先完全关掉旧标签页再打开本页。扫码后会先出现课前自诊；点「进入课件」后会先构建细胞总览，其余环节在后台分步加载。平板会自动降低画质。若地址栏已有 `?lite=1` 仍提示等待，请点「继续等待」或「先看讲义」，不要再点「用轻量模式重新打开」（那只会重新打开同一页）。请使用 Chrome 或 Edge；用电脑打开同一网址通常更顺畅。

## 离线使用

下载本仓库中的 `index.html`，双击用 Chrome / Edge 打开即可离线使用。
